# 第2回 見本

[第2回の資料](../../docs/session02/README.md) の成果物「環境設定手順書」の見本です。受講者はハンズオンの手順3でテンプレート（`docs/session02/assets/環境設定手順書.md`）を作業場所にコピーし、手順ごとに埋めていきます。

- [環境設定手順書.md](環境設定手順書.md): 新人が読んで再現できることを目標にした手順書の例。PATH（`.bashrc`）、apt、プロキシ（環境変数・apt・社内 CA 証明書・curl と git の確認）、うまくいかないときの切り分け、元に戻す方法を含む。社内固有の値（プロキシのアドレス、CA 証明書）はプレースホルダーのままにしてある

見どころ:

- 手順ごとに「確認」があり、読み手が成功したかを自分で判断できる
- 「うまくいかないとき」を、`curl` の表示と終了コードから止まった段階を引ける表にしている
- 「元に戻す方法」がある
- パスワードを書かず、認証がある場合の扱いを付録に分けている

ハンズオンを終えてから見てください。受講者の作業場所は `workspace/session02/` です。第4回の手順7で、隣の人がこの手順書の「確認」の行を打って前提を確かめます（隣の人が再現するのは第4回の環境構築手順書）。
