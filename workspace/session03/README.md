# 第3回 作業場所

[第3回の資料](../../docs/session03/README.md) の手順で作業します。デモのサーバ（`docs/session03/assets/web_demo.py`）は、ターミナル①でこのディレクトリから起動します。

ハンズオンが終わると、このディレクトリには次のファイルが残ります。後の回では使いません。

| ファイル | できる手順 | 中身 |
| --- | --- | --- |
| `cookie.txt` | 手順3の `curl -c` | curl が保存した Cookie（`visits` と、ログアウト後は消えた `session_id`） |
| `old-cookie.txt` | 手順3の `cp` | ログアウト前のセッション ID。サーバ側で消したので、もう使えない |

- デモのサーバのデータはメモリだけにあり、止めると消えます。このディレクトリには何も書きません
- 見本（観察した結果の例）は [examples/session03/](../../examples/session03/README.md) です

このディレクトリは Git で管理しません。`git init` しないでください（Git は第5回から、手順書とアプリのリポジトリだけで使います）。
