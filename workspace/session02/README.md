# 第2回 作業場所

[第2回の資料](../../docs/session02/README.md) の手順で作業します。手順3でテンプレートをコピーし、`環境設定手順書.md` をここで書きます。

- 手順3では `~/.bashrc` を書き換えます。必ず先に `cp ~/.bashrc ~/.bashrc.bak` でコピーを取ってください
- プロキシのパスワードは、このディレクトリのどのファイルにも書かないでください

このディレクトリは Git で管理しません。`git init` しないでください（Git は第5回から、手順書とアプリのリポジトリだけで使います）。第4回では、ここに書いた手順書を隣の人に渡して使ってもらいます。
